## 📌 About the Project

**Anthem Workshop** is a lightweight web application developed using Python and Flask to present the Indian National Anthem through a simple and accessible web interface.

The project demonstrates the fundamentals of Python web development, Flask routing, and HTML template rendering. It is designed as a beginner-friendly workshop project that combines simplicity, learning, and national pride.

## ✨ Features

- 🇮🇳 Displays the Indian National Anthem.
- 🌐 Simple and accessible web interface.
- ⚡ Lightweight Flask application.
- 🧩 HTML template-based rendering.
- 🚀 Easy local setup and execution.
- 🎓 Suitable for educational workshops and demonstrations.

## ⚙️ Getting Started

Follow these instructions to run the project on your local machine.

### 1. Prerequisites

Ensure that you have installed:

- Python 3.8 or later
- pip
- Git

### 2. Clone the Repository

```bash
git clone https://github.com/Harshap18/anthem-workshop.git
```

Navigate to the project directory:

```bash
cd anthem-workshop
```

### 3. Create a Virtual Environment

```bash
python3 -m venv venv
```

Activate it on macOS/Linux:

```bash
source venv/bin/activate
```

On Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install Flask
```

### 5. Run the Application

```bash
python app.py
```

### 6. Open in Browser

Visit the following address:

```text
http://127.0.0.1:5000/
```

The application should now be running locally.
